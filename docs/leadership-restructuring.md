# 幹部役割分担の再編成

> **提出日:** 2026年3月10日
> **作成者:** プロジェクト統括責任者 齋 克弥
> **承認:** 甲斐社長

---

## 1. 組織再編の背景と目的

2026年4月の齋の退職に伴い、「プロジェクト統括・進行管理・収益統制」業務を他メンバーへ移行する。

### 基本方針

- **専任PM制を廃止**する
- 齋の役割を解体し、**幹部3名（髙橋・阿久津・森川）に約33%ずつ**責任を分配
- 各メンバーの強みを最大化する形でセグメント化
- 細かい実務（リスト作成・スケジュール入力等）は**宮川らへ移管**し、幹部は「判断・交渉・管理」に徹する

### 狙い

- 8名規模の組織で管理専任PMを置くとスピード低下・ボトルネック化するリスクの排除
- **第6期 目標4億円の必達**
- 組織進化の起爆剤とする

## 4. 幹部3名への役割分配

### 髙橋 ── セグメントA：直クライアント統括と顧客全体の収益統制

#### 担当業務

- 新規「直クライアント」の開拓および商談
- 齋から引き継ぐ直クライアントとのコミュニケーション・進行管理
- 既存直クライアントへの追加提案、資料作成、アップセル交渉
- 顧客全体統括（全案件俯瞰での収支・リスク管理）

#### 任命理由

| 観点 | 内容 |
|------|------|
| **得意分野** | 顧客との深い信頼構築力、細部まで目を配りながら自ら数字を作るプレイングマネージャーとしての総合力が社内最高 |
| **成長期待** | 「最前線の営業トップ」→ 進行管理・既存提案も包括する **COO的ポジション**への進化 |
| **事業インパクト** | 4億円達成には既存顧客のLTV最大化が絶対条件。顧客全体を統括し「進行中の単価引上げ」「炎上の未然防止」を直接握ることで収益基盤が盤石に |

---

### 阿久津 ── セグメントB：デリバリー（納品）統括と管理能力の向上

#### 担当業務

- 品質管理・調達部門の全業務（外注先の開拓・管理、キャストとの連携、満足度向上）
- SNS運用サービスの統括
- 関（業務委託）のディレクション管理

#### 任命理由

| 観点 | 内容 |
|------|------|
| **得意分野** | 幅広いインフルエンサー・タレントの業界知識、豊かなアイデア・発想力 |
| **成長期待** | 「アイデアを出す」だけでなく、ヒトと原価をマネジメントする管理職へ。**真のプロダクト総責任者**への脱皮 |
| **事業インパクト** | アイデアと原価・リソース管理の両立により、外注先（Noway社等）のパフォーマンス安定、調達コスト削減、納品クオリティ底上げ |

---

### 森川 ── セグメントC：代理店統括と組織システム・DX推進

#### 担当業務

- 代理店とのやり取り・進行管理（既存深耕、休眠掘り起こし、新規開拓・信頼構築）
- チーム間調整（髙橋と阿久津のハブ役）
- Salesforce等のシステム環境整備
- DX推進（AI・自動化）

#### 任命理由

| 観点 | 内容 |
|------|------|
| **得意分野** | 相手の懐に一瞬で入り込む圧倒的な対人スキル、状況を打破するフロント力 |
| **成長期待** | 「テレアポ部隊長」→ 代理店チャネルを動かし、DXで社内生産性を引き上げる**次世代の事業開発・マーケティング責任者**へ |
| **事業インパクト** | 代理店折衝の突破力で売上拡大＋社内システム（DX）牽引により、属人的ミス防止・少人数で売上最大化する強靭な組織基盤の完成 |
