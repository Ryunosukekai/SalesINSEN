# 1. なぜ組織を再編するのか

## 背景

- 2026年4月、齋が退職
- 「プロジェクト統括・進行管理・収益統制」の全業務を移行する必要がある

## 基本方針: 専任PM制の廃止

- 8名規模で**管理だけを行う専任PM**を置くと、スピード低下のボトルネックになる
- 齋の役割を**解体**し、幹部3名の強みを活かして**33%ずつ分配**
- 細かい実務は**宮川ら**へ移管 → 幹部は「判断・交渉・管理」に徹する

## 目標

**第6期 売上4億円の必達** と、組織進化の起爆剤にする

---

# 2. 齋の業務 ── 全体像

## 5つの業務カテゴリ

| # | カテゴリ | 主な内容 |
|---|---------|---------|
| A | **案件進行・提案** | クライアント対応、追加提案、リスク管理、外注先管理 |
| B | **キャスティング・品質管理** | キャスト連携、原価調整、アップセル、満足度向上 |
| C | **チーム間調整** | 営業（髙橋）⇔ 品質管理（阿久津）の橋渡し |
| D | **SNS運用統括** | 運用全体の進行、関（業務委託）の管理 |
| E | **数値管理・DX推進** | Salesforce管理、ダッシュボード整備、AI・自動化 |

> これらの**「見えないハブ業務」**を解体することが新体制の第一歩

# 3. 3つの責任領域（セグメント）

業務を「タスクの羅列」ではなく、**収益と組織力を飛躍させる3つのパッケージ**に再構築

|  | セグメントA | セグメントB | セグメントC |
|--|-----------|-----------|-----------|
| **名称** | 直クライアント統括 | 納品統括 | 代理店統括 |
| **サブテーマ** | 顧客全体の収益統制 | 管理機能の向上 | 組織システム・DX推進 |
| **担当** | **髙橋** | **阿久津** | **森川** |
| **主な業務** | 直クライアント対応、アップセル、全案件の収支管理 | キャスト連携、外注先管理、SNS運用統括 | 代理店折衝、チーム間調整、Salesforce・DX |

---

# 4-1. 髙橋 ── セグメントA

## 直クライアント統括と顧客全体の収益統制

### 担当業務
- 新規直クライアントの開拓・商談
- 齋から引き継ぐ直クライアントの進行管理
- 既存顧客への追加提案・資料作成・**アップセル交渉**
- **全案件を俯瞰した収支・リスク管理**

---

# 4-1. 髙橋 ── なぜこの役割か

| 観点 | 内容 |
|------|------|
| **得意分野** | 顧客と深く入り込む信頼構築力。自ら数字を作る**プレイングマネージャーとしての総合力**が社内最高 |
| **成長期待** | 「営業トップ」→ 進行管理・既存提案も包括する **COO的ポジション**へ進化 |
| **事業インパクト** | 4億円達成には**既存顧客のLTV最大化**が絶対条件。「進行中に単価を上げる」「炎上を未然に防ぐ」を直接握ることで収益基盤が盤石に |

---

# 4-2. 阿久津 ── セグメントB

## デリバリー（納品）統括と管理能力の向上

### 担当業務
- **品質管理・調達部門の全業務**（外注先の開拓・管理、キャスト連携、満足度向上）
- SNS運用サービスの統括
- 関（業務委託）のディレクション管理

---

# 4-2. 阿久津 ── なぜこの役割か

| 観点 | 内容 |
|------|------|
| **得意分野** | 幅広いインフルエンサー・タレントの業界知識と、豊かな**アイデア・発想力** |
| **成長期待** | アイデアだけでなく「ヒトと原価」のマネジメントを担い、**真のプロダクト総責任者**へ脱皮 |
| **事業インパクト** | アイデアと原価管理を両立 → 外注先（Noway社等）のパフォーマンス安定、**調達コスト削減**、納品クオリティ底上げ |

---

# 4-3. 森川 ── セグメントC

## 代理店統括と組織システム・DX推進

### 担当業務
- **代理店**とのやり取り・進行管理（既存深耕、休眠掘り起こし、新規開拓）
- チーム間調整（**髙橋と阿久津のハブ役**）
- Salesforce等のシステム環境整備
- **DX推進**（AI・自動化）

---

# 4-3. 森川 ── なぜこの役割か

| 観点 | 内容 |
|------|------|
| **得意分野** | 相手の懐に一瞬で入り込む**圧倒的な対人スキル**、状況を打破するフロント力 |
| **成長期待** | 「テレアポ部隊長」→ 代理店チャネルを動かしDXも駆使する**次世代の事業開発・マーケティング責任者**へ |
| **事業インパクト** | 代理店折衝の突破力で売上拡大 + DX牽引で属人的ミス防止 → **少人数で売上最大化**する強靭な組織基盤の完成 |

# まとめ

## この再編で実現すること

1. **専任PM制の廃止** → 意思決定スピードの向上
2. **幹部3名の強みを最大化** → 各領域の専門性と責任感の向上
3. **第6期 4億円の必達** → 既存LTV最大化 + 代理店拡大 + 納品品質向上

## 3人の進化

| 髙橋 | 阿久津 | 森川 |
|------|--------|------|
| 営業トップ → **COO** | アイデアマン → **プロダクト総責任者** | テレアポ部隊長 → **事業開発責任者** |

> **「空いた穴を埋める」のではなく、「組織を次のステージに引き上げる」再編**
